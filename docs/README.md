## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 + shadcn/ui
- **QR Generation**: qrcode.react + qr-code-styling
- **QR Scanning**: qr-scanner (nimiq)
- **Deployment**: Vercel
